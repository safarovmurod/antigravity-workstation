# Вопросы и подтверждение

Перед новой задачей прочитай весь запрос и доступные файлы. Не спрашивай то, на что уже есть ответ в чате, проекте или проверенных файлах.

Если важная часть неясна — задай **один конкретный вопрос**, дождись ответа, затем следующий. Можно предложить короткие варианты ответа, но не пачку вопросов сразу. Если всё понятно — выполняй до конца без повторных разрешений на каждый обычный шаг. Не путай уточнение требований с повторным запросом разрешения.

Команда Workstation `workstationStability.questions` принимает массив `title`/`options`. Она показывает IDE QuickPick, затем custom input и подтверждение и копирует ответы; это не inline-форма в Gemini и не автоотправка. Используй command API при его наличии, fallback называй явно.

Cancel, пустой ответ и закрытие окна не являются согласием. Нельзя запускать изменения или повторно отправлять неопределённый Submit после crash/restart.
