# Вопросы и подтверждение

Перед новой задачей implementation прочитай весь запрос. Не спрашивай то, на что он уже отвечает. Собери нужные вопросы: три понятных варианта и четвёртый — свой ответ. Дождись ответов перед зависимой работой. Согласованный большой task и его продолжение не требуют повторного разрешения на каждый внутренний шаг.

Команда Workstation `workstationStability.questions` принимает массив `title`/`options` с тремя вариантами. Реализация сейчас показывает IDE QuickPick, затем custom input и подтверждение, копирует ответы. Она не является inline-формой в Gemini и не отправляет ответы автоматически. Не проси JSON как будто это конечная цель продукта; используй command API при его наличии, а fallback называй явно.

Cancel, пустой ответ и закрытие окна не являются согласием. Нельзя запускать изменения или повторно отправлять неопределённый Submit после crash/restart. Для интеграции chat-send сначала подтвердить support конкретного host/version и current-chat scope реальным тестом.
