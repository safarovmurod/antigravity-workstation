# Воссоздание интерфейса по скриншоту

Читать только при задаче по скриншоту или визуальному совпадению. Основной workflow теперь находится в установленном skill `~/.gemini/config/skills/in-chat-screenshot-to-code/SKILL.md`: он адаптирован из оригинального пользовательского ZIP issue638 с сохранённым source hash. Прочитай его для этой задачи; этот старый собственный reference служит только кратким указателем, не заменой исходного skill.

1. Открой исходный скриншот. Зафиксируй viewport, блоки, размеры, отступы, шрифты, цвета, borders, изображения и состояния. Если исходник отсутствует, запроси его; не выдумывай детали.
2. Проверь существующие компоненты, стили, assets, framework и responsive breakpoints. Используй реальные assets и текущие conventions. Не заменяй изображения произвольными placeholders.
3. Сверстай крупные области, затем typography и мелкие детали. Сохрани текущие handlers, routes, API и state, если изменение логики не поручено.
4. Запусти приложение, сделай скриншот с тем же viewport. Сравни рядом или overlay. Исправляй конкретные расхождения: координаты, размеры, переносы, цвета, line-height. Повтори сравнение после исправления.
5. Проверь мобильный размер, keyboard focus, overflow, loading/error/empty состояния и отсутствие console errors. Не называй результат «1:1» без фактического визуального сравнения.

Источник: https://github.com/abi/screenshot-to-code/issues/638. Сетевой redirect по-прежнему заблокирован, но пользователь загрузил оригинальный ZIP напрямую:11938 bytes, проверенный SHA-256 cdf478612a67fa37116bfd18de0e16f44adbee07953a34cf852a742b04134590. Мак-метаданные не импортируются. LICENSE внутри ZIP отсутствует; MIT родительского webapp не выдаётся за подтверждённую лицензию attachment. Новая адаптация сохраняет stack/реальные assets и делает render/compare обязательными; live Gemini activation не доказана одним копированием.
