# Воссоздание интерфейса по скриншоту

Читать только при задаче по скриншоту или визуальному совпадению. Это собственный локальный workflow; он не является ZIP из стороннего issue.

1. Открой исходный скриншот. Зафиксируй viewport, блоки, размеры, отступы, шрифты, цвета, borders, изображения и состояния. Если исходник отсутствует, запроси его; не выдумывай детали.
2. Проверь существующие компоненты, стили, assets, framework и responsive breakpoints. Используй реальные assets и текущие conventions. Не заменяй изображения произвольными placeholders.
3. Сверстай крупные области, затем typography и мелкие детали. Сохрани текущие handlers, routes, API и state, если изменение логики не поручено.
4. Запусти приложение, сделай скриншот с тем же viewport. Сравни рядом или overlay. Исправляй конкретные расхождения: координаты, размеры, переносы, цвета, line-height. Повтори сравнение после исправления.
5. Проверь мобильный размер, keyboard focus, overflow, loading/error/empty состояния и отсутствие console errors. Не называй результат «1:1» без фактического визуального сравнения.
