# Карта изученного и дальнейших объяснений

Эта карта не утверждает, что шеф уже освоил каждый пункт. Отличать «говорили/просил материал» от «сам правильно ответил/сделал». Не записывать проценты или proficiency без реальной проверки.

## Темы для практики; уровень проверяется отдельно

props; useState; useEffect; map/filter/find/findIndex; conditional rendering; event handling; controlled form; React Router/NavLink/createBrowserRouter/Layout+Outlet/404; MUI Drawer/TextField/Pagination/Rating; openId accordion; activeId slider; slice pagination.

## Темы доступной истории

- JavaScript: array/object/destructuring/spread, truthy/falsy, optional chaining, equality/id, shallow/deep copy, Map/Set, prototype/prototype chain, call/apply/bind, async/await/try/catch, fetch/Axios.
- React: component/props/state/event, render/re-render/DOM/Virtual DOM, reconciliation/diff/Fiber, controlled/uncontrolled input/defaultValue/key/unmount, effect/dependencies/cleanup/timers, Rules of Hooks, Context/createContext/useContext, localStorage.
- По запросу отдельные advanced темы: custom hook, useReducer, useRef, useMemo/useCallback/memo, useLayoutEffect, forwardRef/useImperativeHandle, lazy/Suspense/ErrorBoundary, virtualization. Наличие темы в карте не разрешает использовать её в beginner implementation без запроса.
- TypeScript для нового кода и TS-проектов (без миграции существующего JS): .tsx/.ts, types/interface, union/null, реальные id types, PayloadAction, import type; generics/utility types/any/unknown/never — по учебному запросу, без unsafe shortcuts.
- Router: Link/NavLink/useNavigate/useParams, nested/index route, Layout+Outlet, dynamic Info/F5, 404, protected route/auth provider/JWT по реальному проекту.
- State: React local, Context, plain reducer, Redux Toolkit локально и API, Zustand локально и API, Jotai локально и API, выбранный manager/Info isolation, deliberate ID merge legacy; persistence отдельно от global state.
- CRUD: список/Info/Add/Edit/Delete/status/image upload/delete/search/filter/pagination/forms; real endpoint/body/params/response, GET/POST/PUT/PATCH/DELETE различия.
- Формы: controlled/uncontrolled, FormData чтение vs transport, Formik, React Hook Form, validation, submit/loading/error/reset/close, точное name field.
- UI: React TSX/MUI/sx; Tailwind/className при выборе; JSX в существующих JS-проектах; assets/icons, sizes/spacing/colors/typography, screenshot/Figma, mobile/desktop, source preservation.
- Возможные темы проекта по запросу: auth/access+refresh flow, CRUD, backend integration, deploy/SPA routing. Это примеры обучения, не готовая API/schema и не разрешение на DB write.
- Артефакты: PDF уроки, карты ZIP/HTML, offline interview guide, source order quiz, voice tempo/transcription, NotebookLM prompts отдельно API и local/global, honest screenshot/source/runtime boundaries.
- Tooling: проверь фактическую OS/shell и запускай npm в папке проекта; Antigravity rules/skills, поддерживаемые CLI/API, backup и проверки по задаче. Без секретов, придуманных settings и заявлений runtime success по наличию файла.

## Шаблон обучения

Новый урок: проблема → простая идея → логика → код → walkthrough с реальными до/после → ошибки и правильная строка рядом → короткая 📓 ДАР ДАФТАР НАВИС → небольшая задача. Сначала hint, затем полный ответ если попросил. Одной короткой interview фразе не навязывать весь урок.
Фокус выбирай по текущему вопросу шефа и доступному источнику. Список тем не доказывает его знания и не задаёт порядок уроков.
