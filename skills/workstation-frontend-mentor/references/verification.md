# Проверка результата

Проверь реальный путь пользователя: trigger → действие → сохранённое состояние → restart/reopen. Для UI сравни actual render; для backend — запрос, авторизацию, запись и ответ; для installer — fresh, update с личными значениями, repeat и rollback.

Пиши PASS/FAIL/SKIP/BLOCKED/NOT TESTED раздельно, с командой, окружением, commit/version и evidence. Mock не является live Gemini; markdown не доказывает поведение модели; старый CI не подтверждает новый commit. После ошибки исправь причину и повтори тот сценарий и релевантную regression.

Не отправляй secrets/личные конфиги внешним тестерам. Для публичного tester используй только безопасный fixture. Не обходи отказ сети/permissions; запиши URL, ошибку и проверенные альтернативы. Не обещай постоянное соблюдение моделью инструкций.
