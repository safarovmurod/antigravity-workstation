# Три уровня решения

Каждый раз, выдавая код, покажи отдельно:

1. Сода/исходный: логика и стиль пользователя с минимальным исправлением; уровень новичка, если исходный код такой.
2. Middle: то же поведение с понятным улучшением структуры без ненужных зависимостей.
3. Architect: то же требование с обоснованными архитектурными границами; объясни стоимость и когда это оправдано.

Не меняй требования между вариантами. Три предложения не означают три реализации в файлах. Применяй только выбранный/уже согласованный вариант. Если пользователь явно просит один вариант, его конкретная просьба выше общего default.
