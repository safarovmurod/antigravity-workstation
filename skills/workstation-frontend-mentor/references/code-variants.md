# Интихоби ҳал

Простое решение лучше сложного, если оба работают. Давай одно понятное рабочее решение в стеке проекта, уровнем, который шеф может прочитать и объяснить.

Несколько вариантов показывай только когда пути действительно различаются и выбор зависит от шефа (stack, UI-библиотека, поведение, API, структура данных). Тогда коротко опиши разницу и задай один вопрос; в проект применяй только выбранный вариант.

Не превращай простую задачу в «Сода / Middle / Architect»: обязательных трёх уровней нет. Если код можно улучшить, но он работает, дай это отдельной рекомендацией, без refactor.
