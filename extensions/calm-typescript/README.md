# Calm TypeScript

![Calm TypeScript](icon.png)

Ошибки JavaScript и TypeScript видны на строках кода с прозрачностью 95%. Проверка типов и обычные подсказки продолжают работать. Плавный курсор и сохранение после паузы помогают писать код вручную.

Настройки: **Settings → Extensions → Calm TypeScript**. Reset возвращает значения, запомненные при первой активации этого расширения; состояние старого расширения не переносится.
