# Проверка настроек в IDE

Открой **View → Output → Workstation Antigravity Stability**. Команда **Workstation: Apply and Check Editor Settings** применяет и проверяет настройки активного профиля.

- `applied` — настройки применены.
- `waiting` — нужно нормально закрыть все окна Antigravity.
- `needs-attention` — настройке мешает override проекта или ошибка применения; смотри указанный файл.
- `unavailable` — настройка отсутствует в установленной версии IDE или расширения.

Настройки `.vscode/settings.json` и `.code-workspace` могут иметь приоритет над пользовательскими. Helper сообщает конфликт и не переписывает проект молча.

**Reconnect MCP** перезагружает подключение MCP после ручного выбора команды. Успешная загрузка конфигурации не заменяет авторизацию сервиса.

**Calm TypeScript: Reset Managed Editor Settings** возвращает значения, которые меняло это расширение. Проверка TypeScript и обычные подсказки остаются активными в спокойном режиме.
