# Проверка Setup 2.2.2

Дата: 18 октября 2026 года. Репозиторий: `safarovmurod/antigravity-workstation`.

## Изменения

- Oxc получает актуальный VSIX из официального Microsoft Marketplace при каждом install/update. Равная или более новая установленная версия пропускается. Ошибки загрузки, несовпадение manifest, несовместимость с IDE и отсутствие регистрации завершаются ошибкой, без очистки старых копий.
- После успешной проверки актуального пакета старые папки и повторные регистрации управляемых расширений убираются из активного каталога. Пакеты и изменяемый индекс сохраняются в приватном backup. Чужие расширения с похожими именами сохраняются. Без корректной текущей регистрации очистка не выполняется.
- Bootstrap сначала получает текущий commit `main`, скачивает весь исходник на доступный D: или в `%LOCALAPPDATA%` текущего пользователя и запускает install и Doctor из одной скачанной копии. Каждый запуск использует новую папку. Исходник сохраняется; временный ZIP удаляется. `-DownloadRoot` позволяет явно задать другую папку.
- Исправлено имя корневой папки ZIP после переименования репозитория. На Windows используется системный `tar.exe` с удалением длинной обёртки GitHub; операции PowerShell поддерживают длинные пути. Запасной Git checkout включает `core.longpaths` только для своей команды.
- Команда README требует Setup >=2.2.2. Тест аудита проверяет публикуемые файлы и по умолчанию не читает персональные MCP-конфиги пользователя.

22 skipped относятся к проверкам, требующим отдельного native-окружения, и Windows symlink fixtures. Наличие сети, разрешения Windows и совместимость будущих версий IDE/расширений зависят от конкретной машины; при сбое установщик выводит ошибку, а не фиктивный успешный результат. Doctor для latest-расширений проверяет локальную регистрацию, а онлайн-проверка выполняется во время install/update.

Тест опубликованной команды: `npm run test:bootstrap:live`. Он скачивает реальный исходник GitHub и применяет конфигурацию дважды в отдельном тестовом профиле, без установки в профиль пользователя.
