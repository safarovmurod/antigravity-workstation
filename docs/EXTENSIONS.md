# Расширения и настройки

[Установка и обновление — одной командой](../README.md#quick-start). Полный набор устанавливает 25 обязательных расширения; Jelly Cursor остаётся необязательным. Существующие посторонние расширения сохраняются.

| Расширение | Назначение |
|---|---|
| Highlight Matching Tag | Подчёркивает парные HTML/JSX-теги. |
| HTML End Tag Labels | Показывает имя блока у закрывающего тега. |
| htmltagwrap | Оборачивает выделенный код в HTML-тег. |
| Auto Rename Tag | Меняет имена парных тегов вместе. |
| DotENV | Подсвечивает синтаксис `.env`. |
| Turbo Console Log | Добавляет `console.log` для выбранной переменной: Ctrl+Alt+L. |
| EditorConfig | Применяет отступы и пробелы из `.editorconfig` проекта. |
| Prettier | Форматирует код: Ctrl+Shift+F. Отступ по умолчанию — 3 пробела. |
| npm Intellisense | Предлагает установленные пакеты внутри строки import. |
| Path Intellisense | Предлагает пути файлов и папок; в JS/TS import не добавляет расширение исходника. |
| Tailwind CSS IntelliSense | Предлагает классы Tailwind в настроенном Tailwind-проекте. |
| ES7+ React snippets | Предлагает шаблоны React в начале меню подсказок; rfc/rafce + Tab или Enter. |
| Better Comments Next | Выделяет TODO и другие пометки в комментариях. |
| Image preview | Показывает изображения при наведении и в поле редактора. |
| Russian Language Pack | Переводит стандартный интерфейс редактора на русский. |
| Oxc | Подключает Oxlint; проекту нужен `oxlint` в зависимостях. |
| Material Icon Theme | Показывает иконки файлов и папок. |
| Error Lens | Показывает диагностику рядом с кодом. |
| Import Cost | Показывает оценку размера импортируемого пакета. |
| Calm TypeScript | Делает диагностику прозрачной на 80%, сохраняет проверку типов, добавляет плавный курсор и сохранение после паузы. |
| Workstation Stability | Применяет настройки в активном профиле и показывает конфликты проекта. |
| Git Branch Panel | Показывает ветки Git, создаёт и переключает их. |

Автоимпорт экспортов библиотек выполняет **встроенная служба JavaScript/TypeScript**. Установи библиотеку в проект, открой файл JS/TS/JSX/TSX, начни имя экспорта и нажми **Ctrl+Space**. Выбери вариант с нужным пакетом и нажми Enter — редактор добавит import. Пакету нужны корректные exports/типы; настройки не могут создать отсутствующие экспорты.

Настройки набора находятся в [settings.json](../config/settings.json), клавиши — в [keybindings.json](../config/keybindings.json), список расширений — в [extensions.json](../config/extensions.json). Auto Save работает после паузы 1000 мс; форматирование использует Prettier и уважает `.editorconfig` проекта. Конфигурация Prettier самого проекта имеет приоритет.

Live Server не устанавливается. При обновлении его прежняя установка переносится в backup и удаляется из активного профиля. Настройки AI отключены; обычный IntelliSense остаётся.

В 3.0.6 разделены владельцы функций: Prettier форматирует, Oxc запускает Oxlint на вводе (Oxfmt выключен), Auto Rename Tag меняет парные теги (`editor.linkedEditing` выключен). Встроенная JS/TS-служба предлагает символы и автоимпорты; Path Intellisense отвечает за относительные пути, а npm Intellisense — за имена установленных пакетов. Подсказки внутри строк включены. Проверка CSS/SCSS и ошибки Tailwind включены; стандартные Tailwind-директивы не считаются неизвестными CSS-правилами.

Обновление сохраняет личные цвета, ассоциации файлов и редакторов, исключения поиска/наблюдения, языковые mapping и дополнительные terminal-профили. Настройки проекта по-прежнему имеют приоритет; Workstation Stability сообщает путь конфликтующего файла.

Stability Helper 1.3.4 чинит только проверенные версии HTML End Tag Labels, Auto Rename Tag, Path Intellisense и Import Cost. Перед записью проверяет идентификатор, версию и SHA-256 исходника, сохраняет оригинал и повторно проверяет результат. Новая или изменённая вручную версия требует отдельного аудита; она не перезаписывается. Auto Rename Tag, Path Intellisense и Import Cost проверены также официальным верификатором подписи Microsoft Marketplace.

Jelly Cursor остаётся необязательным: совместимого стабильного выпуска для проверенного engine 1.107.0 сейчас нет. Плавный курсор обеспечивает Calm TypeScript.

В 3.0.7 обычное обновление переиспользует исправные совместимые Gallery-пакеты без повторного скачивания. Регистрация, manifest, engine, архитектура, зависимости и основные файлы проверяются локально; повреждённые/несовместимые установки исправляются через официальный download. Это проверка существующей установки, а не новая проверка подписи её издателя. Workstation Stability 1.3.4 также объявляет shortcut-ы как defaults самого расширения, поэтому они действуют и в именованных/новых профилях, где расширение включено; defaults самого helper уступают пользовательским назначениям. При повторной установке installer обновляет управляемые слоты клавиш в Default; этот прежний режим установки не изменён.
