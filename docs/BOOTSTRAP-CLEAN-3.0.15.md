# Команда 2: ранняя проверка закрытой IDE — 3.0.15

Предоставленный лог относится к `-CleanExtensions`, то есть команде **2**. Он показывает успешную загрузку архива 8.45 MiB за 6:28, затем отказ до изменения профиля:

```text
Clean extensions requires every Antigravity window to be closed normally.
Run this mode from a separate PowerShell window; no setup changes made.
```

Это защита работающей IDE: удалять загруженные расширения при открытом редакторе нельзя. Недочёт setup 3.0.14 состоял в поздней проверке — пользователь сначала ждал загрузку, затем получал ошибку prerequisite и стек PowerShell.

Соседнее сообщение `ENOENT ... .workstation-source.json` означало, что для нового commit ещё нет проверенного локального cache. После него архив успешно скачался. Оно не являлось причиной остановки установки.

## Исправление

- Команда 2 проверяет процессы Antigravity **до установки Node/Git, разрешения Git commit и скачивания исходного архива**. Небольшой bootstrap README всё равно получает перед этой проверкой.
- При открытой IDE печатаются понятные шаги: сохранить работу, нормально закрыть все окна IDE, открыть **Windows PowerShell из меню Пуск** и повторить ту же команду 2.
- Bootstrap возвращает отдельный код **3: установка не запускалась, prerequisite не выполнен**. README обрабатывает его предупреждением без общего `Installation failed` и без утверждения об успешной установке. Это не код 0 и не запрос AI-ремонта.
- Проверка повторяется непосредственно перед установкой: IDE могла быть открыта заново во время скачивания. Загруженный проверенный cache при этом сохраняется для повтора. Последняя защита в Node installer остаётся на случай гонки после проверки.
- Первый cache miss показывается обычным сообщением «No verified cache for this commit yet; downloading it once»; повреждённый cache продолжает проверяться с сохранением исходной причины. Проверки хешей и целостности не отключены.
- В начале каждого запуска явно печатается выбранный режим. Команда 1 сохраняет другие расширения и не получает clean-only требование закрытия IDE. Команда 3 остаётся completion-only.

Все три команды README требуют **3.0.15**. Новых команд не добавлено. Содержимое editor settings, keybindings, agents, skills, rules, шрифтов и локальных helper-пакетов этим исправлением не меняется.

## Как выполнить команду 2

1. Сохранить открытые файлы.
2. Нормально закрыть **все** окна Antigravity. Не использовать принудительное завершение ради установки.
3. Через Пуск открыть Windows PowerShell вне IDE.
4. Вставить целиком актуальную **команду 2 из README**.

Ожидаемая строка режима: `Selected mode: 2 - full setup with extension cleanup (requires closed IDE)`. Успех требует завершения установки и Doctor; пауза, сохранённая repair-задача или ожидание перезапуска не заменяют проверку.

## Проверки

Добавлены проверки трёх имён процесса IDE, обычного обновления при открытой IDE, clean-паузы до prerequisites/загрузки, повторного открытия IDE перед установкой, preview без изменений, ошибки получения списка процессов, обработки exit 3 в README и нормального первого cache miss. Windows PowerShell 5.1 runtime-сценарии проверяют, что установка и Doctor не вызываются при clean-паузе.

Основные тесты установки: **348/348**; portable PowerShell-набор: **62/62**; guards Windows smoke/controller: **17/17**. Синтаксис PowerShell проверен. Добавлен отдельный реальный Windows IDE probe: запуск production bootstrap при открытом редакторе должен вернуть exit 3 без проверки Node/Git, скачивания и создания source cache. Результат Windows CI фиксируется после завершения. Отдельный лог ошибки команды 1 пользователь пока отложил; приведённый clean-mode лог не доказывает сбой обычного режима.
