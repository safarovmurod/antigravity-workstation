# Проверка установки на ноутбук — 3.0.7

Обычная команда № 1 из [README](../README.md#quick-start) повторно применяет настройки, rules, skills, agents, hooks и MCP. Уже установленные совместимые Gallery-расширения используются без повторного скачивания. Локальные Workstation-расширения обновляются из проекта; посторонние расширения сохраняются. После установки нужно сохранить работу, полностью закрыть Antigravity и открыть его снова.

Исправлены подтверждённые проблемы:

- Раньше latest-tracked Gallery-расширения скачивались заново при каждом запуске. Теперь проверяются CLI inventory, запись в `extensions.json`, идентификатор и версия manifest, engine/build date, архитектура, зависимости, `.obsolete` и основные файлы пакета. Исправный зарегистрированный пакет сохраняется; недостающий, несовместимый или повреждённый проходит обычную установку с проверкой официального пакета. Локальная проверка не заявляется повторной проверкой подписи всех уже установленных файлов.
- Повреждённая старая копия не должна мешать выбору исправного дубликата. Известные зарегистрированные старые копии переносятся в backup; содержимое, принадлежность которого не подтверждена, сохраняется с предупреждением. Выбранный совместимый пакет остаётся активным.
- В именованном профиле реальные user keybindings были пустыми: installer писал их только в Default. Stability Helper 1.3.4 теперь объявляет все 16 управляемых shortcut-ов как extension defaults. В именованном профиле helper должен быть включён. Defaults helper уступают личным user shortcut-ам; helper не переписывает профильные файлы клавиш. Installer при повторной установке, как и раньше, обновляет совпадающие управляемые слоты в Default. Проверка именованного профиля не заявляется проверкой сохранения личных переопределений этих слотов после запуска installer.
- Последнее сообщение bootstrap скрывало исходную причину установки за `exit 1`. Теперь в сохранённой source-папке остаются `setup-install.log`, при запуске Doctor — `setup-doctor.log`, а при ошибке — `setup-failure.json`. Внизу терминала повторяются исходная причина, точный код завершения и пути к отчётам. Логи ограничены последними 256 КиБ; распространённые значения credentials скрываются. Кириллица и Unicode читаются как UTF-8, исходная console encoding восстанавливается после команды. Doctor запускается после успешного installer.

Прошли 310 основных тестов без пропусков, 31 portable PowerShell-сценарий, 13 guards оркестрации smoke и 64 сфокусированные проверки Gallery/recovery. Реальный VS Code 1.107.1 в отдельном Linux-профиле проверил физические Ctrl+Shift+F/Ctrl+Alt+F, Ctrl+Space/Alt+Space, приоритет личного shortcut-а и сохранность обоих профильных файлов. Отдельный реальный CLI-прогон использовал уже установленные Gallery-расширения с нулём попыток download/install. Windows full-catalog smoke расширен повторным проходом всех обязательных Gallery-пакетов, который падает при любой попытке скачать или переустановить пакет.

Код опубликован в [`2cab475`](https://github.com/safarovmurod/antigravity-workstation/commit/2cab475ccd8edf40f6903a317425aa20f7e1dffc). Реальная загрузка именно этого commit, установка и повторное применение 1068 payload-файлов с проверкой всех хешей, quiet-command и согласованный rollback прошли. [Setup checks](https://github.com/safarovmurod/antigravity-workstation/actions/runs/39303619625) для этого commit прошёл на Linux, Windows x64 и ARM64, включая Windows PowerShell 5.1, настоящие HTTP transports/длинные пути и повторную регистрацию шрифта. Отдельный [Native Windows IDE smoke](https://github.com/safarovmurod/antigravity-workstation/actions/runs/39303619456) с настоящим открытием IDE и полным Gallery-каталогом на момент фиксации отчёта ещё выполняется; успешный результат нового UI-прогона пока не заявляется.

Предыдущий финальный код 3.0.6, `a86cfd283ca2c74c09b3f1689a653ac10b4e4013`, уже прошёл [Setup checks](https://github.com/safarovmurod/antigravity-workstation/actions/runs/39281963646) и [Native Windows IDE smoke](https://github.com/safarovmurod/antigravity-workstation/actions/runs/39281963770), включая x64 и ARM64. Это подтверждение базового выпуска; результаты нового 3.0.7 фиксируются отдельно в [verification-3.0.7.json](../specs/001-workstation-refresh/verification-3.0.7.json).

Предоставленный вывод с ноутбука содержит итоговую ошибку wrapper-а для `b363d70`, без предыдущей строки `Setup incomplete` или названия неудачного шага. Поэтому точная причина именно того запуска пока не установлена. При повторной ошибке нужен `setup-failure.json` либо предшествующая исходная ошибка, а не один заключительный `exit 1`.

Настройки проекта (`.editorconfig`, Prettier, workspace settings) имеют приоритет и показываются в отчёте конфликтов Workstation Stability. Вход в сторонние сервисы требует аккаунта, Jelly Cursor остаётся необязательным и несовместимым с проверенным engine. Автоматическая настройка не заменяет эти внешние условия.
