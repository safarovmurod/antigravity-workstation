## Автосохранение, форматирование и три пробела

Напишем намеренно неровный код и остановимся. Через секунду файл автоматически сохраняется. Форматирование покажем отдельным действием: Control Shift F, Control Alt F или явное сохранение. При режиме afterDelay этот редактор не запускает format on save от одного таймера. По умолчанию отступ составляет три пробела, кавычки двойные, точки с запятой отключены. Собственные настройки Prettier и EditorConfig в проекте имеют приоритет.

## Обычные подсказки без AI ghost text

Серый текст AI между строками отключён, но обычное меню подсказок работает. Откроем его сочетанием Control Space или Alt Space. Enter принимает выбранный вариант, Tab раскрывает snippet. В меню оставлены функции, переменные, типы и другие полезные категории. Случайные слова из документов и устаревшие варианты скрыты. Реальный набор вариантов зависит от языка и установленного провайдера.

### 59. editor.inlayHints.enabled

`"off"`

Встроенные серые подсказки типов и параметров между символами скрыты.

**Как увидеть:** Обычные подсказки без AI ghost text: показать значение в каталоге и соответствующий пример в редакторе.

### 60. editor.quickSuggestions

`{"other":true,"comments":false,"strings":true}`

Обычные подсказки появляются в коде и строках; в комментариях автоматическое меню отключено.

**Как увидеть:** Обычные подсказки без AI ghost text: показать значение в каталоге и соответствующий пример в редакторе.

Внутри блока:

- `other = true` — Подсказки в обычном коде включены.
- `comments = false` — Автоматические подсказки в комментариях выключены.
- `strings = true` — Подсказки в строках включены.

### 61. editor.quickSuggestionsDelay

Применяет и проверяет managed settings в активном профиле, поддерживает проверенные исправления расширений и repair task.

**В этой записи:** Пакет подготовлен в изолированном demo-профиле; каждый эффект проверяется отдельно.

**Пример:** Показать настоящий установленный helper и проверку профиля; не утверждать, что AI уже исправил сбой.

## Что не доказывает этот каталог

- Настройки Windows Git Bash показываются как Windows-конфигурация; Linux-терминал не выдаётся за Windows.
- В demo-профиле подготовлено24 пакета. Необязательный Jelly пропущен; обязательный SQL-пакет недоступен из-за сетевого ограничения этой среды и в записи не считается установленным.
- Сохранённая конфигурация не доказывает ответ AI, выполнение MCP, вход в GitHub или подключение SQL.
- Демонстрация Git выполняется с локальным bare-origin; личный аккаунт не авторизуется.
- 263 — число исходных ключей верхнего уровня, а не число независимых визуальных эффектов. Вложенные языковые блоки содержат повторяющиеся общие правила.
- Значение памяти TypeScript1024 — исходный шаблон. Итоговая установленная величина вычисляется по RAM.
- Параметры Jelly сохранены для совместимости; само расширение по умолчанию не устанавливается.
