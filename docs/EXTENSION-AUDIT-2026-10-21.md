# Аудит расширений и настроек — Setup 3.0.12

Проверено 21 октября 2026 года. Найдены и исправлены три неработающих имени настроек. В актуальной конфигурации **263 ключа, 16 записей клавиш и 26 уникальных расширений каталога**: 25 обязательных и необязательный Jelly Cursor.

## Исправления

| Раньше | Сейчас | Результат |
|---|---|---|
| `javascript.suggest.importStatements` | `javascript.suggest.includeCompletionsForImportStatements: true` | Поддерживаемая настройка JavaScript, проверенная в API Antigravity. |
| `typescript.suggest.importStatements` | `typescript.suggest.includeCompletionsForImportStatements: true` | Поддерживаемая настройка TypeScript, проверенная в API Antigravity. |
| `editor.renderValidationDecorations` | `problems.visibility: true` глобально | Включает диагностику через действующий параметр IDE. Старый ключ был внутренней опцией Monaco и игнорировался обычным редактором. |

Установщик удаляет старые имена из пользовательского `settings.json`, включая старую опцию диагностики в языковых блоках. Workstation Stability **1.3.8** применяет новые параметры в активном профиле и убирает старую опцию из управляемых языковых блоков. Личные параметры и точная резервная копия сохраняются; повтор не создаёт одинаковую полную копию. Проектные `.vscode/settings.json`, `.editorconfig` и `.prettierrc` автоматически не переписываются.

Все **три** существующие команды README требуют **3.0.12**. Первая устанавливает полный профиль с сохранением других расширений; вторая устанавливает полный профиль с архивированием посторонних расширений; третья меняет только настройки completion. Для полной настройки используется первая или вторая команда. Шрифт включён в обе полные команды. Четвёртая команда не добавлена.

## Конфликты

- Форматирует Prettier; второй форматтер Oxc выключен, Oxlint остаётся включён.
- Пути TS/TSX предлагает Path Intellisense; дублирующий встроенный path provider выключен. Проверена единственная подсказка без `.ts` в import.
- Auto Rename Tag переименовывает HTML/TSX один раз; native linked editing выключен. Highlight Matching Tag только оформляет тег.
- Editor и Prettier используют 3 пробела. Проектная конфигурация имеет свой приоритет и диагностируется отдельно.
- Native Auto Save сохраняет после паузы 1000 мс; Calm уступает ему. Prettier проверен явным форматированием: Auto Save не считается доказательством запуска formatter.
- AI ghost text выключен; обычные подсказки, snippets и auto-import сохранены.

## Условные параметры и границы проверки

Остальные **16 ключей** не зарегистрированы в тестовом профиле без соответствующих модулей: 12 совместимых переключателей Jelly Cursor, три голосовых параметра и один MSSQL. Они не считаются активными функциями только потому, что записаны в JSON. Jelly по умолчанию не нужен; голосовые параметры реальны, но регистрируются при наличии speech provider, а keyword activation — ещё и chat agent. Параметр MSSQL проверен по официальному manifest версии 1.46.0; пакет SQL в этой облачной среде недоступен из-за сетевого ограничения.

Полный автоматический UI-прогон в Linux Antigravity остановился на React snippet-меню: widget оставался в состоянии Loading. Явный фокус и отключение vendor AI в отдельном диагностическом профиле не устранили это. Поэтому полный native UI-прогон не отмечается успешным. Отдельный native-прогон исправленных import/diagnostic параметров прошёл; `rfc/rafce`, Tab и все 19 проверок расширений прошли в VS Code. Это различие сохранено в отчёте, без подмены одного редактора другим.

Этот отчёт не устанавливает факт входа в личный GitHub, SQL-подключения, ответа модели или живого MCP-вызова. Панель Git проверялась с настоящим локальным репозиторием. Настройки и расширения на пользовательском ноутбуке и его проектные overrides из облака напрямую не видны. Текущий Windows smoke запускается в GitHub Actions после публикации: его результат следует смотреть отдельно от Linux-проверок.
