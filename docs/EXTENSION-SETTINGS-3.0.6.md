# Проверка расширений — 3.0.6

Проверены 26 записей каталога и 60 управляемых параметров расширений по схемам выпусков, совместимых с Antigravity engine 1.107.0. Полный профиль содержит 25 обязательных расширений, lite — 12; Jelly Cursor необязателен.

Исправлено:

- Подсказки внутри строк import и Tailwind включены во всех управляемых языковых профилях. Встроенная JS/TS-служба сохраняет автоимпорт символов; Path Intellisense отвечает за пути, npm Intellisense — за пакеты.
- Path Intellisense 2.10.0 больше не ищет незаконченный префикс имени как папку и не добавляет `.ts` при импорте из TSX. Оригинальный пакет проверен официальным верификатором подписи Microsoft. Исправление привязано к точным версии и SHA-256.
- Auto Rename Tag выбран владельцем парного переименования; встроенный linked editing выключен. Поддержан отдельно проверенный вариант официального пакета 0.1.10; старые hash-пины сохранены. HTML End Tag Labels сохраняет прежнюю защиту от незаконченного кода.
- Import Cost 3.3.0 корректно разбирает собственный виртуальный ESM-entry в CommonJS-проекте. Правило `javascript/auto` применяется только к этому временному файлу, не к коду пользователя. Подпись исходного пакета Microsoft проверена; исходник/результат закреплены SHA-256.
- Prettier остаётся форматтером, Oxc запускает Oxlint на вводе, Oxfmt выключен. CSS/SCSS и применимые проверки Tailwind включены.
- Installer и API активного профиля объединяют личные цвета, ассоциации файлов/редакторов, исключения поиска/наблюдения, mapping и terminal-профили с управляемыми значениями. Группы соединений SQL больше не входят в управляемые настройки.

Локально прошли 303 основных теста, 12 проверок оркестрации Windows smoke и 29 сетевых сценариев PowerShell. Реальный VS Code 1.107.1 в отдельном Linux-профиле проверил 59 параметров установленных расширений и выполнил все проверки команд, провайдеров и отображения: npm/relative import, React snippets и настоящий Tab, Emmet, Prettier/Auto Save, диагностика TS и Oxlint, HTML/TSX paired rename, htmltagwrap, Turbo Console Log, Tailwind, CSS, два словаря, DotENV, иконки, hover картинки, TODO, closing labels, underline и реальный Import Cost. Git Panel выполнил fetch/push в принадлежащий тесту локальный bare remote.

Windows x64/ARM64 smoke расширен теми же проверками провайдеров и команд при настоящем открытии и повторном запуске Antigravity. Тест официальных native-схем: 12/12; recovery guards: 4/4; проверки безопасного ремонта расширений: 20/20. Import Cost для React 19.3.1 дал 8240 байт, gzip — 3182 байта; проверены и результат провайдера, и реальная надпись. Linux-fixture вынесена из `/tmp`, который Import Cost использует для виртуальных файлов; CSS-файл явно выбирает Tailwind config через `@config`.
