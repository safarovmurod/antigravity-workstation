# Установка и обновление

Выбери один из [трёх режимов README](../README.md).

1. Открой **Antigravity IDE → Terminal → New Terminal → PowerShell**.
2. Вставь команду выбранного режима целиком. Она загружает свежий `main`, фиксирует commit и применяет весь набор из одного источника.
3. Проверь итог: ошибка этапа означает неудачную установку, даже если предыдущие этапы завершились.
4. Сохрани работу, закрой все окна IDE и дождись `applied` в указанном `statusFile`.
5. Открой IDE заново. Для русского интерфейса требуется полный перезапуск.

**Обычный режим** обновляет настройки и обязательные расширения, убирает старые управляемые копии и сохраняет остальные расширения. **CleanExtensions** сохраняет backup всех пользовательских расширений, удаляет их и устанавливает полный набор заново; запускай его в отдельном Windows PowerShell после закрытия всех окон IDE. **QuietCompletion** меняет только AI-подсказки, сохраняя расширения и разрешения чата.

Source сохраняется в `D:\WorkstationSetup`, а при недоступности D: — в `%LOCALAPPDATA%\WorkstationSetup`. Настройки устанавливаются в профиль текущего пользователя Windows. Резервные копии находятся в `%USERPROFILE%\.gemini\backups`.

Папка исходников и папка IDE независимы. IDE обнаруживается на любом диске по активному процессу, PATH, Uninstall или App Paths в реестре Windows. Пробелы, кириллица и другое имя папки допустимы. Для вручную перенесённой IDE без регистрации укажи `$env:ANTIGRAVITY_INSTALL_DIR = 'D:\Папка с IDE\My editor'` в начале выбранной команды README; нужен абсолютный путь к папке с `.exe`. Неверный путь останавливает установку.

Нужны Windows 10 x64 build 19041+ либо Windows 11 x64/ARM64, установленная и один раз открытая IDE, интернет, Node.js 24+, npm 10+ и Git. Bootstrap проверяет инструменты и при необходимости устанавливает через winget. Login и Windows UAC пользователь проходит сам.

Настройки native AI и разрешений принимаются только для проверенного build из [каталога совместимости](../config/native-compatibility.json). Неподдерживаемый build останавливает установку до изменения профиля.
