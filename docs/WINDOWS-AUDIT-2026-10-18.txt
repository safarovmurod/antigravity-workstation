ВЫВОД
Нельзя подтвердить «нет ошибок и работает на любом Windows». Реальные скачивания и установка проходят в проверенных условиях, но найдены три воспроизводимых дефекта. Они не исправлены в рамках этого аудита.

ПОДТВЕРЖДЁННЫЕ ОШИБКИ
1. Doctor ошибочно отмечает отсутствующие Oxc и Code Spell Checker как pass. Причина: undefined === undefined в lib/doctor.js:230. Проверено на отдельном CLI inventory без этих расширений.
2. Запасной Invoke-WebRequest в PowerShell 5.1 не принимает выходной путь с префиксом \\?\, который добавляет scripts/bootstrap.ps1:20. Один и тот же GitHub-файл с обычным путём скачивается, с таким префиксом — FileOpenFailure. Точная последовательность README без curl дошла до ZIP-ошибки, затем успешно получила тот же commit через Git. Поэтому это неисправный основной транспорт, а не доказательство безусловного отказа всей команды.
3. При длинном DownloadRoot ZIP скачивается, но tar не может перейти в каталог распаковки; Git init затем падает с Filename too long. Поддержка длинных путей неполная. scripts/bootstrap.ps1:80,95.

ГРАНИЦЫ ПОДДЕРЖКИ
Полная native-установка сейчас допускает только одну проверенную Windows x64 сборку Antigravity 2.5.5 с точным хешем main.js. Другая сборка будет отклонена до изменения настроек.
Чистые ВМ разных выпусков Windows 10/11, ARM64/x86 и установка Node/Git/winget с нуля не проверены. windows-latest здесь — Windows Server 2025.
Локально не запускались регистрация шрифтов Windows, браузерный GUI, авторизованный чат и все функции/активация каждого расширения. MCP-проверка подтверждает запуск и list_tools, а не полное выполнение всех workflows.
Первый изолированный прогон CLI дал сбой инвентаризации; последующие прогоны прошли. Причина первого сбоя отдельно не установлена.

БЕЗОПАСНОСТЬ ПРОВЕРКИ
Рабочие настройки и extensions.json пользователя до/после CLI-проверок имеют одинаковые хеши. Все изменения выполнялись в тестовых каталогах. Исходный код проекта не менялся; commit и push в этом аудите не выполнялись.
