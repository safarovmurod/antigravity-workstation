## Failure conditions

| Condition | Expected protection exercised |
| --- | --- |
| Network offline / HTTP 503 | Reject missing-font download, clean temporary staging, do not claim installation |
| Corrupt font checksum | Reject before calling OS installation |
| Corrupt/missing bundled font | PowerShell staging rejects before installation |
| Conflicting personal font file | Preserve the personal bytes and refuse overwrite |
| Existing verified font files / repeat | Reuse without unnecessary download in the existing staging path |
| Global settings write failure | Restore earlier writes |
| Concurrent personal change during rollback | Preserve the concurrent value and report incomplete rollback |
| Unknown/personal theme or token rules | Preserve through setup/ownership migration |
| GSD owned legacy/native MCP entry | Add only the intended flag, preserve personal servers, plan without writing |
| GSD repeat / malformed config / foreign server / other runtime | No redundant migration or unapproved write |
| Matching/changed browser screenshot | Real browser reports zero mismatch for matching fixture and detects changed background |
| Official SQLite/config corruption, disk-full, uninitialized profile, WAL, rollback | Existing production preflight/recovery suites run against the SHA-verified official bundle |

Network and corrupt-download failure tests use explicit unit fixtures; they are not represented as a real network outage. The browser diff is a controlled live browser fixture, not a live Gemini screenshot-to-code reconstruction.
