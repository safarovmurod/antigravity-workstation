4. PowerShell-скрипты шрифтов и GitHub Panel при длинном исходном пути получают
   короткую временную копию необходимых файлов; после запуска она удаляется.

   управляемых значений и пользовательских/project/policy overrides.
   Defaults без отдельного значения в plan остаются информационными.
   Реальные конфликты сохраняют статус active. Исправлено чтение известных

У Oxc есть отдельное условие: oxlint должен быть dependency самого проекта.
Это штатная модель Oxc, не дефект installer. Setup обновляет расширение,
но не редактирует package.json чужих проектов. В тесте dependency установлена
только в disposable workspace. Основной formatter этого профиля — Prettier.
Официальное описание: https://oxc.rs/docs/guide/usage/linter/editors

с точным хешем main.js. Vendor-логи не пустые: в частности, MSSQL 1.46.0 сообщает

WORKSTATION_IDE_EXE (установленная непереносимая Antigravity) и

затем npm run test:ide:profile. Контроллер копирует расширения в новый временный
профиль, регистрирует текущий VSIX helper и устанавливает только тестовый Oxlint.
