# Режим практики и обучающий воркфлоу (Practice Workflow)

Данная конфигурация включает глобальный движок практики и автоматическое определение обучающего контекста для начинающего frontend-разработчика.

---

## 1. Команды движка практики (Practice Engine)

Скрипт движка расположен глобально по пути `%USERPROFILE%\.gemini\scripts\practice-engine.mjs`.

В любом учебном проекте в `package.json` можно подключить вызовы:
```json
"scripts": {
  "practice:new": "node ~/.gemini/scripts/practice-engine.mjs new",
  "practice:open": "node ~/.gemini/scripts/practice-engine.mjs open",
  "practice:save": "node ~/.gemini/scripts/practice-engine.mjs save"
}
```

### Доступные команды:

1. **Создание новой ветки практики:**
   ```bash
   npm run practice:new -- day1
   npm run practice:new -- redux-practice
   ```
   - **Защита (Dirty Guard):** Если в текущей ветке есть несохранённые изменения, переход блокируется во избежание «утечки» кода.
   - **Базовая ветка:** Новая ветка всегда создаётся строго от чистого `origin/main` (или локального `main`). Ветка `main` остаётся нетронутым чистым шаблоном.
   - Нельзя создать ветку с именем `main` или `master`.

2. **Сохранение прогресса практики:**
   ```bash
   npm run practice:save
   ```
   - Добавляет все изменения в текущей ветке (`git add --all`).
   - Создаёт коммит `Save <branch>`.
   - Делает отправку на удалённый репозиторий (`git push -u origin <branch>`).
   - **Запрет на main:** Команда `practice:save` строго запрещена на ветке `main/master`.

3. **Открытие существующей ветки практики:**
   ```bash
   npm run practice:open -- day1
   ```
   - Проверяет отсутствие незакоммиченных изменений в текущей ветке.
   - Переключается на ветку локально или настраивает отслеживание с `origin`.
   - Выполняет безопасный `pull --ff-only`.

## 2. Автоматическая активация режима обучения (AI Signals)

Агенту не требуется писать `/mansur-practice` вручную. Режим обучения активируется автоматически при совпадении любого из условий:

- **Имя ветки Git содержит:**
  `day1`, `day2`, `day-1`, `day-2`, `redux-practice`, `zustand-test`, `jotai-test`, `test123`, `learn-hooks`, `exercise-01`, `try-zustand`, `practice/*`.
- **В тексте запроса присутствуют ключевые слова:**
  "практика", "учусь", "exercise", "beginner mode".

### Поведение агента в режиме практики:
1. **Терпеливое пошаговое объяснение:** 1 логический шаг за 1 сообщение. Агент не выкатывает сразу весь CRUD из 5 файлов.
2. **Фокус на логике:** Простое объяснение потока данных (Кликнул -> получил id -> вызвал функцию -> axios запрос -> обновил стейт -> обновил UI).
3. **Строгий TypeScript:** Только `.tsx` и `.ts`, без `any`, без `@ts-ignore`.
4. **Сохранение авторского стиля:** Агент не заменяет названия переменных и функций на сложные абстракции.
