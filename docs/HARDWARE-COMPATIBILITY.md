# Совместимость ПК

Название модели и бренд не ограничиваются. Полная установка рассчитана на Windows 10 x64 build 19041+ и Windows 11 x64/ARM64 с проверенным build Antigravity IDE 2.5.5. У Google нет Windows-версии IDE для x86/x32: [официальные загрузки](https://antigravity.google/download). PowerShell x86 в Windows x64 распознаётся как x64.

Лимит TypeScript выбирается автоматически по доступному Windows объёму физической RAM. Это верхняя граница heap одного процесса TypeScript, а не резервирование памяти и не общий лимит редактора.

| RAM | Лимит TypeScript |
|---|---|
| 2 GiB | 512 MiB |
| 4 GiB | 1024 MiB |
| 8 GiB | 2048 MiB |
| 16 GiB и больше | до 4096 MiB |

Расчёт: четверть физической RAM с шагом 256 MiB, в диапазоне 256–4096 MiB; при недоступном счётчике — 1024 MiB. Все настройки, функции языка и 24 обязательных расширения сохраняются. На компьютере с другим объёмом RAM повторное обновление пересчитает лимит.

VSIX скачивается на диск частями: в RAM не собирается весь ZIP. Manifest, CRC, версия, совместимость engine и SHA-256 проверяются; прерванный или повреждённый собственный partial-файл удаляется.

Перед изменением профиля показываются RAM и свободное место для загрузок, профиля, расширений и backup. Полный диск останавливает установку. Мало доступной памяти/места или недоступный счётчик дают предупреждение. Наличие свободного места не доказывает, что его хватит для любого будущего пакета и размера backup.

Проверки ресурсов не обходят ограничения Windows, S mode, организации или требования самого IDE. Каждый физический ноутбук, объём RAM и драйвер отдельно не проверялись; абсолютная гарантия для любого ПК невозможна.
