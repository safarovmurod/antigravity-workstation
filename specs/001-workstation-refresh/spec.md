# Antigravity Workstation

Профиль Windows устанавливается из последнего commit основной ветки одной командой PowerShell. Обычное обновление сохраняет сторонние расширения; явный чистый режим сохраняет backup и пересобирает набор расширений. Отдельный режим выключает только AI-подсказки.

Обязательные результаты: работающий автоимпорт из установленных npm-библиотек; обычный IntelliSense без AI ghost text; Auto Save; согласованные отступы editor и Prettier по 3 пробела с сохранением собственных конфигов проекта; Highlight Matching Tag, HTML End Tag Labels, dotenv, Turbo Console Log и EditorConfig; отсутствие Live Server в новом наборе; нейтральные названия собственных расширений и иконки; миграция предыдущего профиля без дублирующихся правил.

README: три кратких раздела на русском, реальные снимки интерфейса, без истории версий. Изменения применяются только к проекту и GitHub. Локальный профиль Antigravity не изменяется.

Приёмка: локальные проверки логики, реальный download/extract в отдельную папку, настоящие проверки IDE на Windows x64 и ARM64 в GitHub Actions; проверка ошибок и backup/restore. Нельзя утверждать, что login стороннего сервиса или policy организации отключены.

IDE может находиться на C:, D: или другом диске в переименованной вложенной папке с пробелами и кириллицей. Папка исходников, установка IDE и профиль пользователя определяются независимо. При отсутствии активного процесса/PATH зарегистрированное расположение важнее оставшейся старой копии в стандартной папке. Для перенесённой вручную IDE без регистрации предусмотрен явный абсолютный путь.

Поддерживаемые Windows/архитектуры не зависят от бренда компьютера. Лимит памяти TypeScript рассчитывается от физической RAM: четверть объёма с шагом 256 MiB, от 256 до 4096 MiB; при неизвестном объёме — 1024 MiB. Полный каталог и функции языка сохраняются. Большие VSIX загружаются на диск частями; проверка manifest/CRC/версии/engine и SHA-256 не требует копии всего ZIP в RAM. До записи профиля выводятся RAM и свободное место; полный диск отклоняется, недоступный счётчик и малая доступная память дают явное предупреждение. Это адаптация ресурсов, а не обещание совместимости с Windows x86 или каждым физическим устройством.
