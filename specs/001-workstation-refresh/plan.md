# План

1. Проверить фактические настройки и manifest расширений совместимой IDE.
2. Обновить профиль редактора и каталог последних совместимых расширений.
3. Ввести нейтральные имена с миграцией старых ownership-реестров, правил и расширений.
4. Добавить явный чистый режим с проверенным backup и rollback; сохранить обычный режим обновления.
5. Пересобрать собственные VSIX с иконками, краткими описаниями и документацией.
6. Подготовить README из трёх инструкций и реальные изображения из отдельной среды CI.
7. Проверить download, install, повторный install, очистку, rollback, IntelliSense, форматирование и сохранение. Исправить найденные ошибки и опубликовать один итоговый commit в main.

Попытка штатной инициализации `specify init --here --integration codex --script ps` завершилась ошибкой установленного launcher: `uv trampoline failed to canonicalize script path`. Файлы требований, плана и задач ведутся в проекте; глобальные инструменты и настройки пользователя не изменяются.

8. Убрать фиксированные 4 GiB для TypeScript, сократить пик RAM при скачивании больших VSIX и добавить предварительную диагностику ресурсов. Проверить несколько объёмов RAM, полный диск, повреждённые/прерванные загрузки, сохранение полного каталога, затем настоящий Windows CI и опубликованный downloader.
