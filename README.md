Это отдельная ветка для видео. Исходный проект и три команды установки находятся в [ветке main](https://github.com/safarovmurod/antigravity-workstation/tree/main). [Подробное руководство и таймкоды](https://github.com/safarovmurod/antigravity-workstation/blob/main/docs/VIDEO-GUIDE.md).

В одном ролике: реальные набор кода и клики в Antigravity, JetBrains Mono, плавный курсор, React snippets, Emmet, автоимпорт, отступ 3 пробела, Prettier и Auto Save, TypeScript, Git Branch Panel и полный разбор 263 настроек, 16 keybindings и 26 записей расширений. Каталог объясняется через реальные страницы редактора с выделением и прокруткой; основные функции демонстрируются действиями в коде.

Запись сделана в официальном Antigravity IDE 2.5.5 для Linux x64, изолированный extension-test profile. Подготовлены 24 пакета; загрузка SQL расширения ограничена сетью, Jelly необязателен. Git-панель выполнила настоящие commit/push в локальный origin. Авторизация личного GitHub показана инструкцией; ответ AI и живые вызовы MCP не выдаются за проверенные. Два native AI Tab переключателя отключены реальными кликами в отдельном тестовом профиле; Windows-персистентность по Linux-записи не заявляется.

Озвучка синтезирована локально: Denis/Piper medium через [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) (Apache-2.0). [Карточка голоса](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/denis/medium) указывает датасет CC0. Исходный видеоряд воспроизводится в масштабе времени 1:1; слайд-шоу, повторов движения и замороженных последних кадров нет.

MP4 находится в медиа-ветке, чтобы обычная установка из main, её ZIP, npm и Git-fallback не скачивали видео. Полное клонирование всех веток может получить и эту ветку.
